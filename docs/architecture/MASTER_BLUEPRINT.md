# F1 Telemetry Analysis Dashboard (2025)

## Vision

A professional Formula 1 telemetry and race analysis platform built using FastF1, Python, and a modern web frontend.

The application should allow exploration of every race, every session, every driver, and every team from the 2025 Formula 1 season through an interactive interface.
